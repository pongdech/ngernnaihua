# Pongdech Channels site

Home page, Privacy Policy and Terms of Service for the Google OAuth (Branding) and Meta app settings.

## Before uploading

Replace every `YOUR_EMAIL@example.com` (in index.html, privacy.html, terms.html) with the contact email you want shown publicly.

## Publish with GitHub Pages

1. Create a new **public** repository, e.g. `channels`.
2. Upload `index.html`, `privacy.html`, `terms.html`, `style.css` to the root of the repo.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. Wait 1–2 minutes. The site is at `https://<username>.github.io/channels/`.

## URLs to paste

| Field | URL |
|---|---|
| Application home page | `https://<username>.github.io/channels/` |
| Privacy policy | `https://<username>.github.io/channels/privacy.html` |
| Terms of service | `https://<username>.github.io/channels/terms.html` |
| Authorized domain (Google) | `<username>.github.io` |

Meta: App settings → Basic → Privacy Policy URL / Terms of Service URL use the same links.
